# Resume Engine v2

Данные лежат в `data/`, профили резюме — в `targets/`, вёрстка — в `templates/` и `assets/`.
Сборка: `python scripts/build.py --all` → `output/site` (его и публикует GitHub Pages).

## Данные

| Файл | Что внутри |
| --- | --- |
| `master.yaml` | имя, контакты, локация, титулы и summary по профилям, метрики, подписи секций, строки интерфейса |
| `experience.yaml` | места работы; `end: present` печатается как «донині» / «present» |
| `projects.yaml` | ключевые проекты: период, роль, описание, `stack`, необязательная `link` |
| `skills.yaml` | стек, сгруппированный по разделам (бекенд, данные, фронт, интеграции, доступы, качество, десктоп, подходы) |
| `achievements.yaml` | «Что я сделал» — результаты, а не обязанности |
| `domain.yaml` | предметная область: фискальные и торговые термины |
| `education.yaml` | образование и сертификаты (`kind: degree` / `certificate`) |
| `languages.yaml` | языки и уровни |
| `side_projects.yaml` | публичные репозитории со ссылками — блок «Код на GitHub» |

Любой элемент с тегами попадает в профиль, если его тег есть в `include_tags` целевого профиля;
в профиле `full` показывается всё. У проекта дополнительно есть `primary` — список профилей,
где он показывается первым: так в `.NET` наверх идут UAM и журналы, а в `ai` — голосовой пайплайн.

Профилей пять: `full`, `dotnet`, `delphi`, `web`, `ai`.

Ещё три рычага отбора: `bullet_order` у места работы — какие пункты и в каком порядке показывать
в каждом профиле (индексы 0–7 у АТБ и 0–6 у фриланса стабильны — на них ссылается одностраничник);
`detail_in` — в каких профилях позиция раскрывается пунктами, в остальных она сворачивается в строку
«Раніше»; `primary` у групп стека и записей опыта — что идёт первым в конкретном профиле.
У образования `tags` необязательны: запись без тегов показывается везде, годы у дипломов не выводятся.

## Что генерируется

Для каждого профиля: `index.html`, а также `resume.pdf` / `resume.docx` / `resume.md` (английские)
и `resume.uk.pdf` / `resume.uk.docx` / `resume.uk.md` (украинские). Кнопки скачивания на странице
переключаются вместе с языком интерфейса.

## Поведение страницы

- Тема: «Авто» ставит светлую с 07:00 до 19:59 по локальному времени, иначе тёмную; выбор запоминается.
- Язык: «Авто» — украинский для киевской таймзоны или `uk`-локали, иначе английский.
- У каждого профиля свой акцентный цвет: Full — изумруд, .NET — фиолетовый, Delphi — сиена, Web — бирюза.
- Печать (`Ctrl+P`) даёт чистую версию без элементов управления.
- PDF собирается шрифтом DejaVu (в CI), локально — любым найденным юникодным шрифтом системы.
